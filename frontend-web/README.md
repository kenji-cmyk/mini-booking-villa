# VStay Web Frontend

React web implementation following `../docs/md/10-design-rule.md`.

## Run

```powershell
npm install
npm run dev
```

The app runs at:

```text
http://127.0.0.1:5173
```

Set the API URL with:

```text
VITE_API_BASE_URL=http://localhost:8080
```

The backend must allow this origin in CORS.
